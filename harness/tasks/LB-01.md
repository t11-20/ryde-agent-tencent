# LB-01 — Evidence workspace and root wiring

**Goal:** add an empty `@fairtrip/evidence` workspace that builds, is importable by the API, and is tested by the root test run, without breaking Lane A.
**Requires:** LB-00 · **Who:** agent · **SPEC:** §3 · **Screenshot moment:** no

## Files

Create: `vitest.config.ts`, `packages/evidence/package.json`, `packages/evidence/tsconfig.build.json`, `packages/evidence/src/index.ts`, `packages/evidence/test/smoke.test.ts`
Modify: `tsconfig.json`, `package.json` (root: two scripts only), `apps/api/package.json`, `package-lock.json` (only via `npm install`), `harness/STATUS.md`

## Steps

1. Create `vitest.config.ts` at the repository root:
```ts
import { defineConfig } from 'vitest/config';

// Root test run: Lane A tests, integration tests and package tests. apps/web runs its own tests.
export default defineConfig({
  test: {
    include: ['tests/**/*.test.ts', 'packages/*/test/**/*.test.ts'],
  },
});
```

2. In the root `tsconfig.json`, add this property after `"include"` and change nothing else:
```json
"exclude": ["apps/web", "**/dist", "node_modules"]
```

3. Create `packages/evidence/package.json` exactly:
```json
{
  "name": "@fairtrip/evidence",
  "version": "0.1.0",
  "private": true,
  "type": "module",
  "exports": {
    ".": {
      "types": "./dist/index.d.ts",
      "import": "./dist/index.js"
    }
  },
  "scripts": {
    "build": "tsc -p tsconfig.build.json"
  },
  "dependencies": {
    "@fairtrip/agents": "0.1.0",
    "@fairtrip/contracts": "0.1.0",
    "zod": "4.6.5"
  }
}
```

4. Create `packages/evidence/tsconfig.build.json` (same pattern as `packages/contracts/tsconfig.build.json`):
```json
{"extends": "../../tsconfig.json", "compilerOptions": {"outDir": "dist", "rootDir": "src", "declaration": true}, "include": ["src/**/*.ts"]}
```

5. Create `packages/evidence/src/index.ts`:
```ts
export const EVIDENCE_PACKAGE_VERSION = '0.1.0';
```

6. Create `packages/evidence/test/smoke.test.ts`:
```ts
import { describe, expect, it } from 'vitest';
import { EVIDENCE_PACKAGE_VERSION } from '../src/index.js';

describe('evidence package', () => {
  it('is wired into the root test run', () => {
    expect(EVIDENCE_PACKAGE_VERSION).toBe('0.1.0');
  });
});
```

7. In the root `package.json`, replace only the values of `"build"` and `"typecheck"`:
```json
"build": "npm run build -w @fairtrip/contracts && npm run build -w @fairtrip/agents && npm run build -w @fairtrip/evidence && npm run build -w @fairtrip/api",
"typecheck": "npm run build -w @fairtrip/contracts && npm run build -w @fairtrip/agents && npm run build -w @fairtrip/evidence && tsc --noEmit",
```

8. In `apps/api/package.json`, add `"@fairtrip/evidence": "0.1.0"` to `dependencies`, keeping alphabetical order (`@fairtrip/agents`, `@fairtrip/contracts`, `@fairtrip/evidence`, `express`, `zod`).

9. Run `npm install` at the root. `package-lock.json` changes; that is expected.

## Verify

- `npm run typecheck` → no errors
- `npm test` → 10 test files pass (9 Lane A + smoke); still 67 Lane A tests
- `npm run build` → creates `packages/evidence/dist/index.js`
- `npm run check:examples` → passes
