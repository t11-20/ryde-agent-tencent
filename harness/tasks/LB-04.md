# LB-04 — GPS metrics: route deviation and pickup

**Goal:** compute route and no-show telemetry exactly as SPEC §5.4–5.6 defines.
**Requires:** LB-03 · **Who:** agent · **SPEC:** §5.4, §5.5, §5.6, §7 (first two tables) · **Screenshot moment:** YES

## Files

Create: `packages/evidence/src/route.ts`, `packages/evidence/src/pickup.ts`, `packages/evidence/test/route.test.ts`, `packages/evidence/test/pickup.test.ts`
Modify: `packages/evidence/src/index.ts`, `harness/STATUS.md`

## Steps

1. `route.ts` exports:
```ts
import type { Fixture, PolicyParams } from './schemas.js';
export interface UnexpectedStop { startTs: string; endTs: string; durationSec: number; lat: number; lng: number }
export interface RouteMetrics {
  referenceMeters: number; actualMeters: number; excessMeters: number; excessPct: number;
  thresholdMeters: number; exceedsThreshold: boolean;
  referenceDurationSec: number; actualDurationSec: number; extraDurationSec: number;
  unexpectedStops: UnexpectedStop[]; pingCount: number; referenceRouteSource: string;
}
export function thresholdMetersFor(referenceMeters: number, params: PolicyParams): number  // §5.4 threshold rule
export function isMaterialDetour(excessMeters: number, thresholdMeters: number): boolean      // strict >
export function findUnexpectedStops(fixture: Fixture): UnexpectedStop[]                       // §5.5
export function routeMetrics(fixture: Fixture, params: PolicyParams): RouteMetrics | null     // §5.4
```
2. `pickup.ts` exports:
```ts
export interface PickupMetrics {
  pickupLabel: string; closestApproachMeters: number; closestApproachTs: string;
  firstWithinThresholdTs: string | null; waitSecondsWithinThreshold: number | null;
  driverMarkedArrivedAt: string | null; cancelledAt: string;
  maxPickupDistanceMeters: number; minWaitSeconds: number;
  checks: { withinDistance: boolean; waitedMinimum: boolean };
}
export function isWithinPickupDistance(meters: number, params: PolicyParams): boolean  // <= max
export function meetsMinimumWait(seconds: number, params: PolicyParams): boolean       // >= min
export function pickupMetrics(fixture: Fixture, params: PolicyParams): PickupMetrics | null  // §5.6
```
Compare ping times with `toEpochSeconds`, never with string comparison.
3. Export both modules from `src/index.ts`.
4. `test/route.test.ts`:
- for R1, R1S, R2, R3 assert every number in SPEC §7's route table (`toEqual` on the numeric fields);
- R1 `unexpectedStops` equals `[{startTs: '2026-10-02T11:13:58Z', endTs: '2026-10-02T11:16:58Z', durationSec: 180, lat: 1.315, lng: 103.885}]`; R2 and R3 have none;
- `routeMetrics` is `null` for X1 (GPS unavailable) and for N2 (wrong category);
- `thresholdMetersFor(4000, params) === 500`, `thresholdMetersFor(8000, params) === 800`, `thresholdMetersFor(7956, params) === 796`;
- `isMaterialDetour(500, 500) === false`, `isMaterialDetour(501, 500) === true`;
- a copy of R1 whose dwell lasts only 100 s has no stop: build it with `structuredClone`, then set the `ts` of the ping at index 13 (the `11:16:58Z` ping) to `'2026-10-02T11:15:38Z'` and assert `findUnexpectedStops(copy)` is empty.
5. `test/pickup.test.ts`:
- every row of SPEC §7's pickup table for N1, N2, N2H, N3, X2, X3;
- `pickupMetrics` is `null` for R1;
- `isWithinPickupDistance(150) === true`, `(151) === false`; `meetsMinimumWait(300) === true`, `(299) === false`.

Get `params` with `loadDataset().policy.params`.

## Stop if

- A golden number is off and 3 attempts have not found the bug. Report expected vs actual for each field. Common causes: rounding each segment instead of the total, comparing timestamps as strings, filtering pings after the cancellation incorrectly.
