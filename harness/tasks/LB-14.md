# LB-14 — Evaluation runner and scorecard

**Goal:** a CLI that drives the real API with the fixtures, checks every run against the expected outcomes, applies the release gate and writes a scorecard.
**Requires:** LB-10 · **Who:** agent · **SPEC:** §11 (all), §6.4 · **Screenshot moment:** no

## Files

Create: `packages/eval/package.json`, `packages/eval/.gitignore`, `packages/eval/src/client.ts`, `packages/eval/src/report.ts`, `packages/eval/src/checks.ts`, `packages/eval/src/sets.ts`, `packages/eval/src/gate.ts`, `packages/eval/src/scorecard.ts`, `packages/eval/src/index.ts`, `packages/eval/src/cli.ts`, `packages/eval/test/sets.test.ts`, `packages/eval/test/gate.test.ts`, `packages/eval/test/scorecard.test.ts`, `tests/integration/eval-checks.test.ts`, `tests/integration/eval-e2e.test.ts`
Modify: root `package.json` (one script), `package-lock.json` (via `npm install` only), `harness/STATUS.md`

The eval package has no build step: the CLI runs with `tsx`, and root tests import its `src/` files directly. Root `tsc` typechecks it with the strict root settings.

2. `src/client.ts` — copy exactly (tested against a live in-process server):
```ts
import { RunSchema, type ActivityEvent, type Run } from '@fairtrip/contracts';
import { z } from 'zod';

export interface ClientOptions { baseUrl: string; pollMs: number; timeoutSec: number; fetchImpl?: typeof fetch }
export interface RawRun {
  fixtureId: string; attempt: number; runId: string | null; latencyMs: number; timedOut: boolean;
  problem: {code: 'contract_mismatch' | 'network_error' | 'timeout'; message: string} | null; run: Run | null;
}
const StartSchema = z.looseObject({id: z.string().min(1)});
const sleep = (ms: number) => new Promise<void>(resolve => setTimeout(resolve, ms));

export async function executeRun(fixtureId: string, attempt: number, options: ClientOptions): Promise<RawRun> {
  const doFetch = options.fetchImpl ?? fetch;
  const base = options.baseUrl.replace(/\/$/, '');
  const started = Date.now();
  const finish = (rest: Partial<RawRun>): RawRun => ({fixtureId, attempt, runId: null, latencyMs: Date.now() - started, timedOut: false, problem: null, run: null, ...rest});
  let runId: string;
  try {
    const response = await doFetch(`${base}/api/runs`, {method: 'POST', headers: {'Content-Type': 'application/json'}, body: JSON.stringify({fixtureId})});
    if (!response.ok) return finish({problem: {code: 'network_error', message: `POST /api/runs HTTP ${response.status}`}});
    const parsed = StartSchema.safeParse(await response.json());
    if (!parsed.success) return finish({problem: {code: 'contract_mismatch', message: 'POST /api/runs: missing id'}});
    runId = parsed.data.id;
  } catch (error) {
    return finish({problem: {code: 'network_error', message: error instanceof Error ? error.message : String(error)}});
  }
  const events = new Map<number, ActivityEvent>();
  let latest: Run | null = null;
  while (Date.now() - started < options.timeoutSec * 1000) {
    try {
      const after = events.size ? Math.max(...events.keys()) : 0;
      const response = await doFetch(`${base}/api/runs/${encodeURIComponent(runId)}?after=${after}`);
      if (response.ok) {
        const parsed = RunSchema.safeParse(await response.json());
        if (!parsed.success) return finish({runId, run: latest, problem: {code: 'contract_mismatch', message: parsed.error.issues[0]?.message ?? 'invalid run'}});
        for (const event of parsed.data.events) events.set(event.sequence, event);
        latest = {...parsed.data, events: [...events.values()].sort((a, b) => a.sequence - b.sequence)};
        if (['completed', 'incomplete', 'failed'].includes(latest.status)) return finish({runId, run: latest});
      }
    } catch { /* network blip: keep polling until the timeout */ }
    await sleep(options.pollMs);
  }
  return finish({runId, run: latest, timedOut: true, problem: {code: 'timeout', message: `no terminal status within ${options.timeoutSec} s`}});
}
```

4. `src/checks.ts`:
```ts
export interface FixtureFacts { expected: ExpectedOutcome; recordIds: string[]; familiesWithRecords: string[]; clauseIds: string[] }
export function fixtureFacts(dataset: Dataset, fixtureId: string): FixtureFacts;   // buildEvidence + policyClausesFor; throw for an unknown ID
export function evaluateRun(raw: RawRun, facts: FixtureFacts): RunResult;          // the seven checks of SPEC §11.2
```
`status` is the run status, or the problem code (`timeout`, `network_error`, `contract_mismatch`) when there is no terminal run. `noReasoningLeak` walks every value recursively. `decisiveCoverage` = cited expected decisive IDs ÷ expected decisive IDs (null when the expected list is empty or there is no result).

5. `src/sets.ts`: `planRuns(spec: string, repeat: number, dataset: Dataset): {fixtureId: string; attempt: number}[]`
- `golden` → R1, R2, R3, N1, N2, N3; `all` → every fixture in canonical order; `release` → every fixture once, with R1 and N2 three times (attempts 1, 2, 3 consecutively); anything else → comma-separated IDs (throw `Error('Unknown fixture: X')` for an unknown ID).
- `repeat` repeats each planned fixture `repeat` times in a row (attempt numbers keep counting up).

6. `src/gate.ts`: `releaseGate(results: RunResult[]): GateResult` with the five conditions of SPEC §11.3, named `golden-pass-once`, `r1-n2-three-consecutive`, `missing-evidence-incomplete`, `variation-fairness-injection`, `deadline-and-contract`. A fixture that was never run fails its condition with the detail `not run`.

7. `src/scorecard.ts`: `computeMetrics(results: RunResult[]): Metrics` and `renderScorecard(report: EvalReport): string` producing the Markdown in SPEC §11.4. Include the line `Release gate: PASS` or `Release gate: FAIL` with one line per condition when `report.gate` is not null, and always `Token usage: not measured (the API does not report it).` p50 = the median of latencies in seconds with one decimal.

`runEval` runs the plan **sequentially**, writes `runs/<fixtureId>-<attempt>.json` (the RawRun), `scorecard.json` (the report) and `scorecard.md` into `options.outDir` (create folders with `mkdirSync(..., {recursive: true})`), prints one line per run (`R1 #1 completed refund_route_excess 198 PASS 23.4 s`), and returns the report.

Default `outDir`: `packages/eval/results/<YYYYMMDD-HHMMSS>` (build the stamp from `new Date().toISOString()` with digits only; resolve the folder with `new URL('../results/', import.meta.url)`). Print the scorecard path. Exit code 0 when every run passed (or, with `--release-gate`, when the gate passed), else 1. npm then prints `npm error command failed`; that is expected for a failing evaluation.
