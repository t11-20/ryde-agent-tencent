## Steps

1. Reuse the `liveConfig`, `createScriptedModel()` and polling helper pattern from `tests/integration/api-source.test.ts` (copy the helper; do not import from another test file).
2. For each expected outcome in `loadDataset().expected` (use `it.each` or a loop of `it` blocks), start a run and wait for a terminal status, then assert:
- status equals `expectedStatus`;
- completed: `result.action.remedyId === expectedRemedyId` and `result.action.amountCents === expectedAmountCents`; incomplete: there is no `result` and `missingEvidence[0]` starts with the first `missingFamilies` entry followed by `:`;
- trace: for `rider` and for `driver` there is at least one `tool.requested`, `evidence.retrieved` and `policy.retrieved` event and exactly one `case.completed`; a `judge.started` event comes after both `case.completed` events; the last event type is `run.completed` or `run.incomplete`;
- the IDs in all `evidence.retrieved` events cover every family that has records for the fixture (use `buildEvidence(fixture, policy).records` to know the families);
- every evidence ID cited in both cases and in the Judge findings is in the fixture's record ID list (SPEC §6.4).
3. The whole file must finish in under 20 seconds.
